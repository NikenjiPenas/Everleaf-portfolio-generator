## Capturing additional screenshots

Place additional, clearly named PNG or JPG captures in this folder. Use safe sample accounts and data. Never include passwords, tokens, secret keys, private portfolio content, or unredacted personal contact details.

The existing checklist identifies items requiring manual capture, including the database view, edit/recovery workflow, and a verified mobile view. Mark a screenshot available only after the file exists and its contents have been reviewed. Do not fabricate or stretch screenshots to imply functionality that was not observed.
